# 🤖 Robot Add-on for Minecraft Bedrock

A custom robot entity for Minecraft Bedrock Edition, created with [Blockbench](https://blockbench.net/). The robot can walk around on its own, look at nearby players, and roll its wheels when moving.

## ✨ Features

- Custom 3D model and texture built in Blockbench
- Wanders and looks around using vanilla AI goals
- Rolling wheel animation that plays when moving
- Spawn egg included for creative mode
- Fully open source — edit and customize as you like

## 📦 Installation

1. Download the `.mcaddon` file from the [Releases](https://github.com/scriptalumen/minecraft-robot-addon) page.
2. Double-click the file to import it into Minecraft.
3. Create a new world and activate both the Behavior Pack and Resource Pack.
4. Run `/summon demo:robot` or find the spawn egg in the creative inventory.

## 📁 What's Included

- **Behavior Pack** — Defines the robot's movement and AI.
- **Resource Pack** — Contains the model, texture, and animation.
- **Blockbench source file** — The original `.bbmodel` file for editing.
